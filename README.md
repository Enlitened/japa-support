# Japa — support site

The support and privacy pages for [Japa](https://apps.apple.com/), a calm counter for
prayers, mantras, affirmations, sacred texts and breath practices on iPhone and iPad.

Published with GitHub Pages:

- Support — https://enlitened.github.io/japa-support/
- Privacy Policy — https://enlitened.github.io/japa-support/privacy.html

Both URLs are referenced from the app's App Store Connect listing. The app's source
lives in a separate private repository.
